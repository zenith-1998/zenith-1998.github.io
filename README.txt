# Academic Personal Website

This folder is a complete responsive academic website inspired by the screenshot you provided.

## Before publishing

1. Replace `Zenith Mondal` and the sample academic details in all HTML files.
2. Put your photograph at `images/profile.jpg`.
3. Put your CV PDF at `files/CV.pdf`.
4. Replace the `#` social/profile links with your real links.
5. Replace sample publications, courses and presentations.

## Run locally

You can simply open `index.html` in a browser.

For best results, use a small local server (for example VS Code Live Server).

## GitHub Pages

Create a GitHub repository, upload all files/folders, then enable:
Settings → Pages → Deploy from branch → main → /(root)

Your site will then be available at:
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

The site uses only HTML, CSS and JavaScript, so no backend or paid software is required.
